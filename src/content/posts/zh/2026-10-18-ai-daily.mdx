  <SectionHead index="03" kicker="模型更新" title="模型名没变，返回结果可能已经变了" />
  <Prose tile>

[DeepSeek 官方更新日志](https://api-docs.deepseek.com/zh-cn/updates/)确认，原来的 `deepseek-flash` 现在指向 V4.1-Flash-1017。已有程序无需换模型名，收到的却是新版本。对维护线上应用的团队，这意味着需要重跑自己的任务样本，检查工具调用和回答格式；这是本文的工程建议，不能由厂商跑分代替。

[模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)把它称为小版本更新，给出与前版的对照结果。Terminal-Bench 4.0 使用 Claude Code 框架，DeepSWE v1.1 使用 Mini-SWE-V2 框架。框架负责组织模型调用和工具交互，成绩反映的是这些测试条件下的表现，不能直接外推到另一套 Agent 的成功率。

官方还称，新版缩短了任务耗时和输出长度。本文没有独立复现速度或费用变化。模型 API 的标价不变，也不代表每个工作流的总费用一定相同；重试次数和工具调用都会影响账单。

<Section canvas id="search-cost">
  <SectionHead index="04" kicker="工具费用" title="搜索与抓取分开计费，先算完整任务" />
  <Prose tile>

[官方指南](https://api-docs.deepseek.com/zh-cn/guides/search)说明，Search 接收查询并返回结构化结果，Fetch 获取单个网页的 Markdown 正文。两者各有每账号每秒 5 次的限制，不互占额度。中文文档的价格均为每千次成功请求 5 元；搜索没有结果、抓取没有正文或请求失败时不计费。

[发布公告](https://api-docs.deepseek.com/zh-cn/news/news261017/)另有一个明确的过渡安排：在 DeepSeek Harness、Claude Code、Codex 中使用 DeepSeek API 时，经服务端工具触发的这部分调用当前未计费，将于北京时间 2026 年 11 月 1 日 00:00 开始按次收费。这个范围不能扩写成所有直接 API 调用都免费。

对开发者的实际意义是多了一套可单独接入的网页检索能力。接入前仍需检查结果相关性与原文可访问性；搜索引擎声称的索引规模和过滤能力属于官方描述，本期没有做质量评测。

  </Prose>
</Section>
