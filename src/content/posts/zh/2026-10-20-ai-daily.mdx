PyTorch 是开发和运行模型的框架。过去迁移到另一类加速芯片，往往还要改模型实现、训练脚本和调试工具。[路透对 AWS 的新采访](https://www.reuters.com/business/retail-consumer/amazon-says-its-ai-chips-will-work-with-popular-coding-language-challenging-2026-10-19/)披露了 TorchNeuron；[PyTorch 官方说明](https://pytorch.org/blog/introducing-torchneuron-native-pytorch-backend-for-aws-trainium/)解释了它如何把 Trainium 注册成框架认识的设备，让已有接口继续使用。

两种执行方式各有用途。即时执行（eager）逐个运行操作，便于断点调试；`torch.compile` 先捕获计算图，再交给后端编译器优化。模型定义与底层硬件之间多了一个标准后端，开发者仍需确认自己的算子和数据类型受支持。

[MiniMax 官方公告](https://www.minimax.io/blog/minimax-m31f)确认 M3.1 Flash 已通过 API、M Plan 与 MiniMax Code 提供服务，权重稍后发布。输入、输出和缓存输入的每百万 token 价格分别为 0.15、0.60 和 0.015 美元。它们对应不同的计费对象，不能把缓存价格当成所有输入的价格。

公司称其中位输出速度达到每秒 170 多个 token，Agent 任务总体使用成本较前代降低 70%。这些数字来自公司评估，本站未独立复现。一次任务要反复调用模型和工具，输出更快或单价更低，都不足以单独证明最终任务一定更便宜；重试次数和完成质量也会改变结果。

另一项重要更新是 [Inception Mercury 3](https://www.inceptionlabs.ai/blog/introducing-mercury-3)。官方称该扩散语言模型已开放 API，提供 100 万 token 上下文；标价为每百万输入 0.20 美元、输出 0.70 美元，发布期暂时优惠到 0.10 / 0.35 美元。每秒 1068 个 token 的速度是厂商在 NVIDIA GPU 上的口径，不能直接与 MiniMax 未统一条件的速度作排名。其公告只给出日期，因此列在边界观察区。

[路透的新调查](https://www.reuters.com/legal/government/how-one-hacker-used-ai-agents-few-thousand-dollars-break-into-scores-sites-2026-10-19/)引用 NorForge 研究，披露攻击者使用 Cairn 组织 Agent 持续尝试入侵。逾 1200 个尝试目标、逾 100 个被攻破站点是报道引用的调查数字；路透另行核对了部分受害者身份，仍未确定数据提取的整体规模。攻击活动早在 9 月开始，本期的新事件是调查公开。

[NorForge 原报告](https://norforge.com/blog/inside_cairn)还暴露了另一侧的问题：攻击方及部分合法测试方的控制面板本身没有做好访问保护，任务记录中含敏感信息。它与路透引用的是同一项原始调查，不能算成两份独立研究互证。本文据此建议将长期运行 Agent 的权限、控制面板和工具日志纳入同一安全检查；站点被列为目标，也不自动等于已经泄露数据。

治理侧，[路透报道的 DeepSeek 限制](https://www.reuters.com/technology/us-banning-chinese-ai-deepseek-government-agency-it-systems-2026-10-19/)针对美国民用联邦机构 IT 系统及有关采购，也涉及使用 DeepSeek 技术的第三方服务。报道中的国家安全风险属于政府判断，本期没有将其写成已经独立验证的技术结论，更没有扩大为所有美国个人设备的禁令。
