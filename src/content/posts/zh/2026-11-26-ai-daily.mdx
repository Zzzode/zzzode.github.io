<Section canvas id="anthropic-messages-rust">
  <SectionHead index="05" kicker="迁移验证" title="Anthropic 公开 Messages API 迁移 Rust 时的验证方法" />
  <Prose tile>
    <p>Messages API 最初用 Python 编写。它要校验请求、组装提示词，再把模型的输出拆成文字和工具调用等内容。Anthropic 早期尝试只用 Rust 改写解析器，随后转向迁移整个服务。</p>
    <p>比较两套实现时，模型只运行一次。Rust 重放同一份模型输出，两边在多个检查点比对。日志记录差异位置和长度等特征，工程师无需读用户的提示词或回复。智能体先在沙盒里尝试修复，工程师审查后，再从影子流量观察同类差异是否消失。</p>
    <p>Anthropic 报告，比较期间每请求 CPU 用量约降 70%，客户 Claude Code 请求的首个 token 中位等待时间约降 20%。CPU 数据来自单一区域，首个 token 数据取自较短时间段。公共流量在 9 月迁移，11 月发布的是工程复盘。</p>
