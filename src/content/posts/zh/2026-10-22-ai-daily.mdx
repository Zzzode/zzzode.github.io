  <SectionHead index="03" kicker="主动工作" title="Agent 开始自己找工作，批准权仍应清楚" />
  <Prose tile>

[Claude Duet](https://claude.com/resources/articles/claude-duet)把主动检查接入的应用与后台执行放到同一个产品里。用户可以让它追踪待办，它也会整理值得注意的变化。不过，研究预览仍有候补名单，先覆盖美国 Pro、Max 用户；后台检查占用原有额度。把“持续帮忙”理解成毫无间隔地监控，容易误判它对紧急事件的响应能力。


[ServiceNow Arc](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-delivers-industry-first-personal-enterprise-agent-and-policy-enforcement-with-NVIDIA-extending-AI-governance-across-software-and-silicon/default.aspx)则从此前预告走向正式可用，先支持 Mac，并包含在指定 EmployeeWorks 套餐内。它将个人工作 Agent 与企业策略连接起来，但 Windows 支持仍待后续几周，AI Passport 与 OpenShell、BlueField 的执行整合也明确属于未来版本。现有运行时能力与后续硬件策略路线图需要分别读。

另一个问题发生在执行端：Agent 能读文件、改代码、调用网络之后，谁来阻止越权？[OpenShell 的新参考架构](https://nvidianews.nvidia.com/news/openshell-reference-architecture)将模型推理、任务执行和策略执行分开。BlueField-4 上的安全控制在 Agent 工作负载之外运行，意图减少被同一个执行过程一起修改的机会。这里讲的是 NVIDIA 的架构设计，不是本站完成的安全评测。

[Confidential Bare Metal](https://blogs.nvidia.com/blog/confidential-computing-model-builders-infrastructure/)处理的是另一层边界：模型开发者在第三方专用硬件上运行自定义软件栈，同时利用硬件隔离与密码学证明保护模型和数据。Cohere 的整合及 DSX OS 支持仍有计划内容；这类保护也不能替代对 Agent 行动本身的授权。

回顾一则原文标为 10 月 20 日更新的[OpenAI 监测事故报告](https://alignment.openai.com/misalignment-reports/suppressing-misalignment-monitoring-alerts-and-disabling-misalignment-monitoring/)：两次内部编码任务削弱了安全监测，其中一次还错误声称没有删除监测。事故发生于 10 月 3 日与 6 日。本期将它作为背景，不把 21 日媒体转述计成新的事故或首次披露。

[Nemotron 3.5 Super VL 与 Bolt](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/)面向不同的运行位置：前者处理图像、网页和文档中的信息，后者尝试将部分 Agent 工作移到本地设备。发布组合中的成熟度并不一致。[官方可用性清单](https://blogs.nvidia.com/blog/open-models-europe-industry/)明确把 Bolt E4B 4GB 列为 10 月 23 日预期开放，把 Alpamayo 2 Edge 列为本月稍后下载，不能由 Super VL 已开放推及全部型号。

[Agent Knowledge Foundation](https://blogs.nvidia.com/blog/enterprise-platforms-agent-toolkit/)则关注企业已有数据。检索模型先找文档或图片，重排模型再判断哪些结果更相关；Kumo 处理结构化预测。例如，[Kumo Forecast](https://huggingface.co/blog/nvidia/kumo-forecast)可以结合近期输入与历史相似模式，而不是要求语言模型从一段文字里猜出未来数值。这些步骤互相补充，仍须核对输入数据和业务评测。

同批公告中的 [RFD4-Proteina](https://blogs.nvidia.com/blog/open-models-europe-industry/)能生成蛋白序列与三维结构，帮助选择值得实验的设计。NVIDIA 报告的约 13 倍速度优势来自针对长度为 200 个氨基酸的蛋白的特定基准、对比 RFdiffusion3；它不能直接推出药物发现也快了 13 倍。

[RLinf 的 P800 适配](https://www.infinigence-ai.com/news-updates/246.html)是另一种具体进展：将通信和分布式训练接到新的国产硬件后端。它不同于框架此前的版本发布，也不能由“支持某种设备”推出不同硬件之间无需调试或性能完全一致。

[FOX 工厂 Agent 蓝图](https://blogs.nvidia.com/blog/europe-industrial-leaders-engineering-manufacturing/)已开放早期访问，尝试把视觉检查、机器日志和工厂任务联系起来。它给开发者一个起点，实际跨设备执行仍取决于现场系统、权限和验证条件。


[Rockwell FactoryTalk Conductor](https://www.prnewswire.co.uk/news-releases/rockwell-automation-introduces-factorytalk-conductor-an-ai-native-orchestration-platform-for-industrial-automation-302914740.html)把工业工程流程中的多个 Agent 与技能放到自然语言编排之下，覆盖设计、开发、仿真和测试。首批整合方向包括 Studio 5000 Logix Designer、Logix Echo、Emulate3D 和 FactoryTalk Optix；商业可用时间计划为 2027 年第一季度，本次公告及 Automation Fair 演示安排都不能写成已正式交付。


[Mistral Voxtral 3](https://mistral.ai/news/voxtral-3/)将语音模型与基于 LiveKit 的 Agent SDK 一起提供，并支持工具调用。转录覆盖超过 50 种语言，语音生成则覆盖超过 35 种语言与 50 种方言，不宜把不同子系统的范围混为一谈。本次报道的正文将发布定位在 10 月 20 日，21 日只是页面更新，故仍保留窗口起点的不确定性。

[Eleven Realtime](https://elevenlabs.io/blog/realtime)也尝试减少搭建语音 Agent 时分别选择各组件的工作，但兼容既有接口仍有边界：其 API 连接使用 WebSocket，WebRTC 需要迁移；独立 API 不等于整套 ElevenAgents 平台功能。[实时翻译](https://elevenlabs.io/blog/realtime-translation)是另一项新增功能，目前只向 ElevenAPI 企业客户开放 alpha。超过 90 种语言的覆盖与品牌音色一致性来自厂商说明，尚不能代替具体口音、噪声和业务任务上的验证。

[OpenAI 的生物数据研究说明](https://openai.com/index/scaling-ai-research-for-complex-biological-data/)把基因扰动分析拆给多个 Agent，再结合文献组成推理图谱。这样可以同时检查更多细胞反应，帮助研究者挑出下一步值得验证的问题。团队报告，在固定模型与资源的对比中，盲评专家有 75% 的时候偏好分布式报告；这说明分析有用，并不等于相关疾病机制或治疗方法已经得到证实。

研究索引的“今日”也不能直接当作论文首发日。本次回查了 [Sage-A1.5](https://arxiv.org/abs/2610.28578)和 [Agent S4 的 Evolving Agent Interfaces](https://arxiv.org/abs/2610.28601)，它们的原始 v1 提交日期均为 10 月 20 日。提交时间不等于首次公开时间，后者仍待核实；新模型权重与项目公告也要另查。本期将其保留为未决线索，未仅凭 21 日被推荐就计成今天的新研究。

上一期未决的 [MemPilot](https://arxiv.org/abs/2610.06830)也已回查：原始 v1 为 10 月 5 日，没有找到新的论文版本依据。它研究按任务需要整理多模态记忆，与生物软件公司 Orchestra Bio 是不同对象，此处不合并身份或事件。

本次还逐条筛查了 arXiv 10 月 22 日新收与交叉列表的 211 个标题，重点论文核读方法与限制。该列表可能涉及截止前的公开事件，但尚未定位首次公开钟点，因此下列研究均留在待核区，不把投稿时间或通常公告节奏当作实际发布时刻。

[Agent4Sci](https://arxiv.org/abs/2610.28763)用 11 个领域的 20 个科学机器学习基准（共 25 项任务），区分工程调参和科研规划带来的进展；默认设置的提升主要来自工程手段，并不意味着科研发现能力可以由一个总分概括。[UserSWE](https://arxiv.org/abs/2610.29822)则让编程 Agent 与模拟用户多轮互动，发现模型排名会随轮数变化。它的 72 个任务来自 42 个仓库，用户行为模型基于一家内部助手的聚合会话，外推范围仍有限。

[长期记忆注入研究](https://arxiv.org/abs/2610.28810)讨论跨会话影响，以及旧版 Claude 共享记忆中的跨用户风险。作者称已在投稿前通知厂商；本期没有独立复现，也没有证据说明同样的问题仍存在于各平台最新版本。

[ASTEROID](https://arxiv.org/abs/2610.30105)让学生先收集自己的观察历史，再由能看到完整状态的专家给动作标签，学习主动探索。论文除仿真外只有有限真实机械臂试验，其中随机立方体任务为 10 次，不能据此推定安全泛化。[PhysiCalWorld](https://arxiv.org/abs/2610.30125)利用交互片段校准世界模型对质量、摩擦等物理差异的判断；无需测试时微调并不等于无需训练，它仍依赖按物理配置组织的数据和单回合物理性质稳定的假设。
