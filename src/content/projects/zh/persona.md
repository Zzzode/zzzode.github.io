description: |-
  一个自托管的 SuperAgent 中枢与全端客户端系统，把分散在各台电脑上的编程 Agent 与个人上下文收拢到同一个入口。底层由单二进制 Go 服务 personad 驱动：一台常驻机器运行 Hub，连接你各台电脑上的 Node，让 Claude Code、Codex、opencode、pi、DSH、Antigravity CLI 等交互式 Agent 继续留在本地运行；出门时可以在 iPhone、Android、Web、Mac、Apple Watch、Vision Pro 以及灵动岛和 Siri 上实时看进度、回问题、批计划，回到桌前直接接着用同一个会话。

  除了跨端协作，Persona 还把对话、联系人与项目沉淀为共享知识库，用 AI 分拣来自飞书、邮件、GitHub、Telegram 与微信的收件箱消息，并把手机通讯录、日历、提醒、照片和健康等能力以本机确认的 MCP 工具开放给 Agent。配合扩展 SDK 与官方扩展市场（Persona Extensions），工具、数据源、消息渠道和 App 界面都能按需接入，所有数据始终留在你自己的硬件上。
